# Refresh the photography collection

Photography is a single page at `/photography/`: an interactive map, year filters, and a continuous image list. Old annual URLs redirect to the same page with `?year=YYYY`; undated images use `?year=undated`. No annual entry pages or gallery pagination remain.

## Import photographs

Original JPG, HEIC, RAF and DNG files remain outside the public repository. Importing is a manual local action, not a background sync or deployment.

1. Wait for iCloud originals to download. Dataless files are skipped and reported.
2. Visually review new photos and add descriptive `alt` text to the private curation JSON, keyed by relative filename. Optional fields: `caption`, `order`, `position`, and a capture `date` verified from original EXIF or by the owner. File modification time is never a capture date.
3. Run with Python + Pillow and native macOS `sips`:

```sh
python3 scripts/import_photography.py --source "/path/to/Photos of the year" --curation "/private/path/curation.json" --report "/private/path/import-report.json" --previous-report "/private/path/previous-report.json"
```

The importer creates 1600 px sRGB WebP display copies and 240 px map thumbnails, stripping EXIF/ICC/XMP. It retains stable IDs and uses source hashes, normalized pixels and rendered bytes to avoid exact duplicates. Visually verified alternate exports can use `duplicate_of`. Similar but distinct frames must not be discarded automatically. Previous imported photos remain if originals are offloaded. Errors fail before applying gallery changes. Source hashes, exact names and provenance stay in private reports outside the repository.

## Refresh positions

The owner explicitly approved placing these photographs at their embedded GPS positions. Public `_data/photo_locations.json` includes only stable photo IDs and latitude/longitude; photographs with missing or invalid GPS stay in the same gallery under **Without location**. Do not infer coordinates from visual content or filenames.

```sh
swift scripts/photo_metadata.swift "/path/to/Photos of the year" "/private/path/original-metadata.json"
python3 scripts/import_photo_locations.py --audit "/private/path/original-metadata.json"
```

Keep the raw audit outside the repository: it contains source filenames and precise capture times. The location join rejects duplicate identities, invalid coordinates, read errors and incomplete source coverage instead of erasing known locations. Review unavailable originals before refreshing. Public image files remain free of embedded metadata; the separately approved map coordinates are intentionally readable by visitors.

## Map and gallery behavior

Leaflet 1.9.4 and Leaflet.markercluster 1.5.3 are vendored under `assets/lib/`, with licenses and source/hash manifest. Normal interactive views request OpenStreetMap tiles over the network with visible attribution; no tile prefetch or offline tile archive. If tiles fail, markers and the gallery remain. If map code fails, gallery and year filters remain; without JavaScript, all image links still work.

Clusters zoom on click and select that place's photographs in the same gallery. **Clear place selection** restores the list; **Show all locations** restores the current year's located photos. Year and missing-location filters combine. The full-size viewer's next/previous controls follow the visible selection. Touch zoom, keyboard controls and reduced-motion settings are supported.

The collection budget is 64 MiB (separate from the research site's 160 MiB budget); thumbnails are at most 32 KiB each and 2 MiB per year. Full-size gallery images load lazily. Review limits explicitly rather than raising them silently. Annual redirect sources are regenerated by `scripts/photography_pages.py`; custom page edits fail with a conflict instead of being overwritten.

Run `make check`, verify desktop/mobile map, clustering, filters, no-location photographs, filtered lightbox navigation, and the old annual redirects. Inspect a network-failure case. All changes remain local until the owner separately approves deployment.
