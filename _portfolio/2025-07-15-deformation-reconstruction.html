Highlights

  • Developed a camera-free, real-time deformation reconstruction system for soft robots using flexible piezoresistive sensors and a 4D Gaussian Splatting model.
  • Designed and produced a flexible 10×10 piezoresistive sensor array (3×3 cm) that conforms to soft robot surfaces.
  • Implemented a GAT-based cage deformer with inverse-distance-weighted propagation on 4D Gaussian Splatting for efficient inference.
  • Achieved ≈ 30 FPS real-time rendering, < 5 % mean 3D displacement error, and < 4.7° bending-angle error under bending/twisting/pressing.
  • Demonstrated zero-shot camera-free reconstruction on unseen objects. Paper accepted to IEEE/RSJ IROS 2026.

Project Overview

During the ISURE Summer Research Program at University of Notre Dame (Jul 2025 – Sep 2025), I worked with Prof. Tingyu Cheng to develop a unified camera-free deformation sensing and rendering system for soft robotics. This project addresses the critical need for accurate 3D reconstruction in dark, confined, or privacy-sensitive environments where traditional camera-based approaches fail.

Technical Approach

Sensor Design & Manufacturing

  • Flexible Sensor Array: Designed and produced a 10×10 piezoresistive sensor array (3×3 cm) that provides sparse pressure-induced resistance readings on the object's surface in real time. The array conforms to soft robot surfaces.
  • Sensor Integration: Deployed the flexible, tileable piezoresistive array on the robot's nominal STL mesh, yielding rich local deformation signals under bend/twist/press deformations.

4D Gaussian Splatting Representation

  • Multi-view Reconstruction: Used a stop-motion protocol to scan key static poses and render dense multi-view images with accurate poses via Blender's virtual cameras.
  • Temporal Densification: Applied video frame interpolation to densify time and enable temporally trackable Gaussian models for every frame using a 4D Gaussian Splatting (4DGS) pipeline.
  • Per-frame Primitives: Each frame yields Gaussian primitives that capture fine surface details of the soft robot's deformation.

Cage-based Deformation Framework

  • Graph Attention Network: Implemented a GNN-based predictor that estimates low-dimensional control displacements for a set of sparse cage control points, rather than directly regressing motions for millions of Gaussians.
  • Inverse-Distance-Weighted Propagation: Displacements are propagated to millions of Gaussians using local weighting strategies, enabling efficient inference while preserving global coherence.
  • Canonicalization: Applied canonicalization per sensed region and re-binding of control points to ensure physical consistency and enable zero-shot generalization.

Performance Results

  • Real-time Rendering: Achieved ≈ 30 FPS real-time rendering of photorealistic RGB images.
  • Deformation Accuracy: < 5 % mean 3D displacement error and < 4.7° bending-angle error under bending/twisting/pressing deformations.
  • Zero-shot Generalization: Demonstrated zero-shot camera-free reconstruction on unseen objects, showing the system's ability to generalize beyond training data.
  • Fine-grained Tracking: Successfully tracked three representative deformation types – bending, twisting, and pressing – with high fidelity.

Key Innovations

  1. Sparse-to-Dense Mapping: Learned an expressive deformation representation from signals that are orders of magnitude sparser than camera observations, bridging the gap between sparse sensor readings and dense 3D geometry.
  2. Efficient Architecture: The cage-based strategy decouples low-dimensional control from high-resolution representation, enabling efficient inference and scalability.
  3. Unified Pipeline: Created a complete end-to-end pipeline from sensor design to real-time rendering, demonstrating practical applicability for soft robotics.

Applications

This camera-free deformation reconstruction system can serve as an effective solution for soft robotics and other applications in:

  • Dark or low-light environments where cameras are ineffective
  • Confined spaces with limited camera access (e.g., endoscopic scenes, minimally invasive instruments)
  • Privacy-sensitive environments where visual recording is restricted
  • Real-time manipulation tasks requiring precise geometry recovery
