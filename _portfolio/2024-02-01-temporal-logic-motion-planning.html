Project Overview

This project (SRP Project ID: X202410561821) focuses on developing a real-time robotic arm motion control system based on Temporal Logic for human-robot interaction. The research explores Linear Temporal Logic (LTL) as a bridge between natural language task descriptions and formal robotic control specifications, enabling expressive task modeling that combines the intuitiveness of natural language with the precision of formal methods.

Under the supervision of Prof. Gang Chen at South China University of Technology, the project has been ongoing since February 2024. The system addresses critical challenges in robotics: task understanding difficulties, inflexible control strategies, and unnatural human-robot interactions, especially in complex multi-step tasks with conditional dependencies.

Technical Approach

LCRL (Logically-Constrained Reinforcement Learning)

The core of our approach is based on LCRL, a novel tool for policy synthesis that combines model-free reinforcement learning algorithms with Linear Temporal Logic (LTL) constraints. Key features include:

  • LTL to LDBA Conversion: LTL formulas are transformed into Limit-Deterministic Büchi Automata (LDBA) to enable reward shaping during RL training.
  • Model-Free Learning: No prior knowledge of the Markov Decision Process (MDP) transition model is required; the system learns from execution trajectories alone.
  • Directional Exploration: The LDBA structure provides directional guidance for exploration, effectively avoiding blind traversal of the state space and improving learning efficiency.
  • Modular Python Interface: Supports multiple RL algorithms (Q-learning, NFQ, DDPG) for flexible selection based on task characteristics.

ROS2 Integration & System Architecture

The system is implemented on ROS2 robotic arm simulation platform, providing a complete integration between high-level task planning and low-level motion execution:

  • High-Level Planning Module: Implements LCRL algorithm to generate task plans that satisfy LTL specifications while adapting to dynamic environments.
  • ROS2 Node Implementation: Developed rclpy nodes to bridge high-level planning results with actual robot actions, enabling seamless communication between planning and execution layers.
  • MoveIt Motion Planning: Integrated MoveIt motion planning framework for collision-free trajectory generation, ensuring safe and efficient arm movements.
  • Gazebo Simulation Environment: Built realistic simulation scenarios in Gazebo to validate system performance under various environmental conditions.

State Monitoring & Feedback Mechanisms

To enable closed-loop control, the system implements comprehensive state monitoring and feedback:

  • Publish-Subscribe Architecture: Uses ROS2 publish/subscribe mechanism to monitor robotic arm and environment states in real-time.
  • Action Feedback: After each action execution (e.g., grasping), sensor topics provide feedback (gripper pressure, object pickup status), which is interpreted as LTL atomic propositions (e.g., "object O has been grasped").
  • Pose Monitoring: Continuously monitors joint states during movement, providing feedback when target poses are reached ("arrived at position P").
  • State Synchronization: Designed information format sends feedback back to the high-level planning module, updating the current LTL automaton state and enabling adaptive decision-making.

Key Technical Challenges & Solutions

Temporal and Concurrency Handling

One major challenge was handling temporal and concurrency issues in ROS2:

  • Asynchronous Execution: The high-level planner cannot stall and wait during arm movement execution; we implemented asynchronous task handling to maintain system responsiveness.
  • Timeout and Failure Management: Developed robust exception handling mechanisms to manage timeouts and task failures in dynamic environments.
  • Real-time Constraints: Addressed ROS2 platform real-time and concurrent execution requirements through careful node design and message queuing strategies.

System Stability and Robustness

Throughout development, we focused on improving system stability and robustness:

  • Iterative Refinement: Continuously iterated, tested, and validated the system to reduce instability and achieve efficient algorithm-platform integration.
  • Multi-Scenario Validation: Tested the system across multiple complex scenarios to ensure consistent performance under varying conditions.
  • Algorithm Optimization: Fine-tuned algorithm parameters and reward functions to improve convergence speed and task satisfaction rates.

Literature Review & Algorithmic Foundation

This project builds upon and extends several state-of-the-art approaches in temporal logic-based robotic control:

LCRL Framework

We studied and adapted the LCRL (Certified Policy Synthesis via Logically-Constrained Reinforcement Learning) framework, which enables model-free RL to learn policies satisfying LTL specifications. Our implementation leverages LDBA structures for efficient reward shaping and directional exploration.

Comparison with Alternative Approaches

  • E-LDGBA-LTL: While providing theoretical advantages for probabilistic satisfaction maximization, this approach has limitations in real-time adaptability and requires known MDP models, which limited its applicability to our dynamic scenarios.
  • Modular Deep RL with E-LDGBA: This modular approach shows promise for continuous motion planning, but the sparse reward problem and slow convergence in training made it less suitable for real-time interactive systems.

System Performance & Results

The system demonstrates strong performance in complex robotic manipulation tasks:

  • Task Satisfaction: Successfully guarantees task fulfillment according to LTL specifications in dynamic environments with moving obstacles.
  • Real-time Responsiveness: Achieves real-time motion planning and execution, enabling interactive human-robot collaboration scenarios.
  • Adaptability: System can adapt to environmental changes and handle unexpected situations through feedback-based state updates.
  • Robustness: Validated across multiple scenarios in Gazebo simulation, demonstrating consistent performance under various conditions.

Research Contributions

  1. LTL-Based Task Specification: Demonstrated the effectiveness of using Linear Temporal Logic for expressive task description in robotic manipulation, bridging the gap between natural language and formal control.
  2. Real-time Integration: Successfully integrated high-level LTL planning with low-level robotic arm execution in ROS2, enabling practical deployment of temporal logic-based control.
  3. Feedback Mechanism Design: Developed a comprehensive state monitoring and feedback system that enables closed-loop control and adaptive task execution.
  4. System Architecture: Designed a modular, extensible architecture that supports multiple RL algorithms and can be easily adapted for different robotic platforms.

Future Work
