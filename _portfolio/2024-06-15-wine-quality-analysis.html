Highlights

  • Comprehensive benchmark of five state-of-the-art ensemble learners on canonical Vinho Verde datasets (1,599 red wine and 4,898 white wine instances).
  • Rigorous data leakage prevention protocol with a stratified held-out test set, training-set cross-validation, and per-fold preprocessing.
  • Achieved weighted F1-scores of 0.693 ± 0.028 (red) and 0.664 ± 0.016 (white) using Gradient Boosting.
  • Measured the accuracy trade-off when compressing each model from 11 variables to its five most important features.
  • Systematic comparison of computational efficiency across ensemble methods, providing practical deployment recommendations.
  • Published in the ACM IPMLP 2025 proceedings, pages 162–170 (DOI: 10.1145/3759928.3759955).

Project Overview

This project addresses the critical challenge of accurate and reproducible wine quality assessment, which has traditionally relied on subjective, labor-intensive tasting panels. Wine quality assessment is essential for production control, yet current methods lack objectivity and scalability. This work presents the first comprehensive, leakage-free benchmark of multiple machine learning methods for wine quality prediction.

Under the supervision of Prof. Chunyang Liao at UCLA during the summer session (Jun 2024 – Aug 2024), I developed a unified machine learning pipeline that systematically evaluates five state-of-the-art ensemble learning algorithms on the canonical Vinho Verde wine quality datasets. The project emphasizes methodological rigor, ensuring no data leakage and providing reproducible benchmarks for future research.

Technical Approach

Rigorous Data Pipeline

Our methodology addresses common pitfalls in machine learning benchmarks through a comprehensive leakage-prevention protocol:

  • Stratified Splitting: 80:20 train-test split with quality-score stratification to maintain class distribution across sets.
  • Training-set Cross-Validation: Five-fold StratifiedGroupKFold within the training set for hyperparameter tuning while preserving an untouched held-out test set.
  • Per-Fold Preprocessing: Independent standardisation (μ=0, σ=1) applied to each fold to prevent data leakage—scaling parameters are computed only on training data within each fold.
  • Class Imbalance Handling: SMOTE-Tomek resampling combined with inverse-frequency cost weighting to address the 3-9 quality score distribution skew in both red and white wine datasets.

Hyperparameter Optimization

  • Search Strategy: Optuna Tree-structured Parzen Estimator with 120-200 trials per model for efficient hyperparameter exploration.
  • Optimization Objective: Weighted F1 is the sole optimization objective used during hyperparameter search.
  • Feature Selection: Two-stage approach using each model's native tree-based importance measure followed by retraining on the five highest-ranked features, subject to a 5% minimum importance threshold.

Evaluation Framework

  • Metrics: Weighted F1 as the primary metric, supplemented by macro F1, macro ROC-AUC, Matthews correlation coefficient, and Brier score.
  • Validation: Results reported on the untouched test set after five-fold model selection within the training data.
  • Computational Profiling: Runtime analysis on an AMD EPYC 9K84 with 128 logical cores, 512 GB RAM, and one NVIDIA H20 GPU.

Key Results & Findings

Performance Hierarchy

Gradient Boosting achieves the highest predictive accuracy across both datasets:

  • Red Wine: Weighted F1 0.693 ± 0.028
  • White Wine: Weighted F1 0.664 ± 0.016

Random Forest and XGBoost follow within three percentage points, demonstrating the competitive landscape among modern ensemble methods.

Feature Importance Analysis

Native tree-based importance rankings identify compact five-feature subsets for each model and dataset. Frequently retained variables include:

  1. Alcohol content
  2. Volatile acidity
  3. Sulphates
  4. Free sulfur dioxide
  5. Chlorides and fixed acidity

Reducing each model-and-dataset combination from 11 variables to its five highest-ranked features decreases median weighted F1 by 2.6 percentage points for red wine and 3.0 percentage points for white wine. This quantifies the modest accuracy cost of using fewer measurements.

Computational Efficiency

Runtime profiling reveals a steep efficiency gradient across ensemble methods:

  • Gradient Boosting: Approximately 12 hours per five-fold optimization study.
  • XGBoost and LightGBM: Approximately 2–3 hours with GPU acceleration.
  • CatBoost: Approximately 1 hour.
  • Random Forest: Approximately 49–50 minutes on CPU.

Practical Recommendations

Based on systematic accuracy-efficiency trade-off analysis:

  1. Production Deployment: Random Forest offers the optimal cost-effectiveness for real-time quality control systems, achieving near-peak accuracy with minimal computational overhead.
  2. GPU-Accelerated Environments: XGBoost provides a balanced alternative when faster retraining is important.
  3. Offline Benchmarking: Gradient Boosting serves as the accuracy ceiling for comparison with future methods, establishing a reproducible baseline.
  4. Feature Engineering: Evaluate compact feature subsets when reduced measurement cost is worth a modest loss in predictive performance.

Research Impact & Reproducibility

This work establishes a unified, leakage-free baseline for comparing ensemble learners on imbalanced multi-class wine-quality data. The documented preprocessing pipeline, hyperparameter configurations, and evaluation metrics support reproducible follow-up studies.

Reproducibility: The paper reports releasing preprocessing scripts, hyperparameter grids, and feature-selection protocols as repeatable baselines.
