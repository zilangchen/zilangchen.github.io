Highlights

  • Comprehensive benchmark of five state-of-the-art ensemble learners on canonical Vinho Verde datasets (1,599 red wine and 4,898 white wine instances).
  • Rigorous data leakage prevention protocol with stratified splitting, nested cross-validation, and per-fold preprocessing.
  • Achieved weighted F1-scores of 0.693 ± 0.028 (red) and 0.664 ± 0.016 (white) using Gradient Boosting.
  • Identified five key physicochemical predictors (alcohol content, volatile acidity, sulphates, free sulfur dioxide, chlorides) that capture 90%+ of predictive signal.
  • Systematic comparison of computational efficiency across ensemble methods, providing practical deployment recommendations.
  • Paper accepted by ACM IPMLP 2025 (DOI: 10.1145/3759928.3759955).

Project Overview

This project addresses the critical challenge of accurate and reproducible wine quality assessment, which has traditionally relied on subjective, labor-intensive tasting panels. Wine quality assessment is essential for production control, yet current methods lack objectivity and scalability. This work presents the first comprehensive, leakage-free benchmark of multiple machine learning methods for wine quality prediction.

Under the supervision of Prof. Chunyang Liao at UCLA during the summer session (Jun 2024 – Aug 2024), I developed a unified machine learning pipeline that systematically evaluates five state-of-the-art ensemble learning algorithms on the canonical Vinho Verde wine quality datasets. The project emphasizes methodological rigor, ensuring no data leakage and providing reproducible benchmarks for future research.

Technical Approach

Rigorous Data Pipeline

Our methodology addresses common pitfalls in machine learning benchmarks through a comprehensive leakage-prevention protocol:

  • Stratified Splitting: 80:20 train-test split with quality-score stratification to maintain class distribution across sets.
  • Nested Cross-Validation: Five-fold StratifiedGroupKFold within training set for robust hyperparameter tuning while maintaining strict separation between train, validation, and test sets.
  • Per-Fold Preprocessing: Independent standardisation (μ=0, σ=1) applied to each fold to prevent data leakage—scaling parameters are computed only on training data within each fold.
  • Class Imbalance Handling: SMOTE-Tomek resampling combined with inverse-frequency cost weighting to address the 3-9 quality score distribution skew in both red and white wine datasets.

Hyperparameter Optimization

  • Search Strategy: Optuna Tree-structured Parzen Estimator with 120-200 trials per model for efficient hyperparameter exploration.
  • Multi-Objective Tuning: Simultaneous optimization of weighted F1-score, training time, and model complexity to find optimal trade-offs.
  • Feature Selection: Two-stage approach using mutual information ranking followed by recursive feature elimination to identify the most informative physicochemical properties.

Evaluation Framework

  • Metrics: Weighted F1, macro F1, balanced accuracy, and per-class precision/recall for comprehensive assessment across all quality levels.
  • Statistical Validation: Five-fold cross-validation with confidence intervals and significance testing to ensure robust performance estimates.
  • Computational Profiling: Runtime analysis on AMD EPYC 9K84 with 128GB DDR5 and H20 GPU acceleration to evaluate practical deployment feasibility.

Key Results & Findings

Performance Hierarchy

Gradient Boosting achieves the highest predictive accuracy across both datasets:

  • Red Wine: Weighted F1 0.693 ± 0.028 (95% CI: 0.665-0.721)
  • White Wine: Weighted F1 0.664 ± 0.016 (95% CI: 0.648-0.680)

Random Forest and XGBoost follow within three percentage points, demonstrating the competitive landscape among modern ensemble methods.

Feature Importance Analysis

Systematic feature ranking reveals that five key physicochemical properties capture 90%+ of the predictive signal:

  1. Alcohol content (ρ = 0.47 with quality) — strongest positive correlation
  2. Volatile acidity (ρ = -0.39 with quality) — strongest negative correlation
  3. Sulphates (ρ = 0.25 with quality)
  4. Free sulfur dioxide (ρ = 0.05 with quality)
  5. Chlorides (ρ = -0.21 with quality)

Dimensionality reduction to these five variables decreases weighted F1 by only 2.6 percentage points (red) and 3.0 percentage points (white), indicating substantial redundancy in the original 11-feature space. This finding has practical implications for production systems where sensor deployment costs matter.

Computational Efficiency

Runtime profiling reveals a steep efficiency gradient across ensemble methods:

  • Gradient Boosting: 12.3 ± 2.1 hours per five-fold study (highest accuracy, lowest efficiency)
  • XGBoost: 2.8 ± 0.4 hours (GPU-accelerated, excellent accuracy-efficiency trade-off)
  • LightGBM: 2.1 ± 0.3 hours (memory-optimized, competitive accuracy)
  • CatBoost: 1.2 ± 0.2 hours (categorical feature optimization, fastest among gradient boosting methods)
  • Random Forest: 47 ± 8 minutes (highest efficiency, excellent for production deployment)

Practical Recommendations

Based on systematic accuracy-efficiency trade-off analysis:

  1. Production Deployment: Random Forest offers the optimal cost-effectiveness for real-time quality control systems, achieving near-peak accuracy with minimal computational overhead.
  2. GPU-Accelerated Environments: XGBoost and LightGBM provide 4-6× speedup with minimal accuracy loss, ideal for batch processing scenarios.
  3. Offline Benchmarking: Gradient Boosting serves as the accuracy ceiling for comparison with future methods, establishing a reproducible baseline.
  4. Feature Engineering: Focus on alcohol content and volatile acidity as primary quality indicators, enabling cost-effective sensor deployment in production environments.

Research Impact & Reproducibility

This work establishes the first standardized benchmark for wine quality prediction, addressing methodological inconsistencies in prior literature. The fully documented preprocessing pipeline, hyperparameter configurations, and evaluation metrics provide a reproducible baseline for future research in imbalanced multi-class classification problems.

Open Science: All code, configurations, and detailed experimental logs are available to facilitate reproducible research in agricultural machine learning applications.
